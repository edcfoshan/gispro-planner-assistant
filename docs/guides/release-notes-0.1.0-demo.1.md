# 发布说明 · 0.1.0-demo.1

## 这是什么

「极思G 规划工作台」Demo 社区预览版。用于查看统一的 ArcGIS Pro 工作台形态，并试用当前已经接入的规划作业模块。

## Demo 当前有什么用

- 前期调研：行政区、POI、地址与坐标处理入口。
- 影像底图与服务、地图跳转、配色和面转 TXT。
- 统一设置、步骤引导、日志和版本信息。
- 应用内检查更新：查询 Release，发现新版后打开下载页。

## Demo 暂不包含

- 全部模块都已达到稳定生产状态。
- 在 ArcGIS Pro 运行期间静默覆盖 Add-in。
- 面向所有 ArcGIS Pro 版本的普遍兼容承诺。
- 未公开的管理员密码或不可审计的公共凭据。

## 安装

下载 `.esriAddinX`，核对 SHA256，双击安装，重启 ArcGIS Pro。当前发布验证环境为 ArcGIS Pro `3.5.2`。

## 密钥

内置天地图 / 吉林一号密钥仍需管理员密码解锁；Demo 暂不公开密码。也可以填写自己的补充密钥。不要提交凭据或业务数据。

## 升级

点击功能区「检查更新」。发现新版后打开 Release 页面，下载新的 `.esriAddinX`，双击安装并重启 Pro。

## 反馈方式

GitHub Issues 提交可复现问题；GitHub Discussions 提规划工作流建议；QQ 群仅供一般交流。日志、截图和样例数据必须先脱敏。

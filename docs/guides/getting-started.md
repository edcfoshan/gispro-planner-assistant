# 使用教程：从一次前期调研开始

本教程覆盖 Demo 当前已接入的主要入口；具体模块仍可能调整。

## 1. 打开工作台

在 ArcGIS Pro 功能区选择「极思G 规划工作台」，点击「作业台」进入统一工作区。首次使用先打开「版本与声明」核对版本，再在「设置」中检查数据获取工具路径、地图跳转与输出位置。

## 2. 前期调研

1. 在地图中选中需要核查的区域或点位。
2. 打开「前期调研」。
3. 在百度、高德或双源模式中查询行政区、POI 或地址。
4. 检查结果表、坐标系与来源状态；行政区无边界时会提示需复核。
5. 选择输出位置，将结果写入表或点 / 面要素。

## 3. 地图跳转

1. 在「地图跳转」中选择百度或高德。
2. 选择网页或作业台方式。
3. 在地图上点选位置，按浏览器提示查看地图或街景。
4. 分享或保存外部链接前，检查其中是否带有业务坐标。

## 4. 影像底图

在「在线瓦片服务」中选择服务，检查坐标系和图层是否正常显示。没有基础密钥时可在设置中填写自己的密钥；不要将凭据写进截图、Issue 或输出成果。

## 5. 面转文本

选择面要素或当前选择集，设置字段、编码与输出目录，先试导出一个地块并检查文本结构，再批量处理。

## 6. 反馈与更新

点击「检查更新」查看最新 Demo Release；下载新 `.esriAddinX` 后双击安装，重启 ArcGIS Pro。遇到问题时附 ArcGIS Pro 版本、Windows 版本、操作步骤和脱敏日志到 GitHub Issues。
